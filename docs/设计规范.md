# 设计规范（管理页）

依据 Apple Human Interface Guidelines（颜色、字体、布局、材质、动效），落到 Web。用户 2026-10-31 的要求：系统原生控件优先；`-apple-system` 系统字体栈和克制的毛玻璃；less is more，页面上不放解释性文案和多余装饰；一个主色加灰阶；留足留白；高频操作一步可达。

这份是验收基准：做完后用 `node tools/e2e/ui-check.mjs` 量实际渲染值，逐项对比本文的数值，差的改到一致；它截的图再逐张人工看。`docs/管理页草图.svg` 只参考布局结构，视觉以本文为准。

## 硬规则

1. **一个主色**：系统蓝，只用在选中状态、主按钮、链接、焦点环、进度条。其余全是灰阶：文字、图标、徽标、边框、背景。状态徽标（失效、重复、要登录、冷门、近期打开）也是灰阶，靠文字区分。
2. **不放解释性文案，要你拿主意的地方除外**：浏览、设置、确认框没有说明段落、提示语、引导句、示意说明；确认框只有标题和一句话。要你拿主意的地方（待处理的每一类、整理页的每一步、弹窗的结果和状态、空状态）各允许一行说明，不超过 24 个字，说清这是什么、该怎么办（2026-11-05 用户同意：列表不说是什么、不给操作，所以看不懂）。空状态是一个灰色图标加一个短句（「没有结果」「都处理完了」）。按钮写动作，有数量的带上数量（「放好 3 条」「删除这 7 条」「删除 49 个空文件夹」），不用「处理」「确定」这类词；标签、表头用 2～6 个字。
3. **不加装饰**：没有渐变、彩色圆点、插画、emoji 装饰；卡片不加投影，靠白底和灰色页面底区分；悬停不上浮、不放大。
4. **原生控件**：`button`、`input[type=search]`、`select`、`input[type=checkbox]`、`dialog`、`progress`、`details`。用 `accent-color: var(--accent)` 统一主色，不自绘下拉框和复选框。
5. **高频操作一步可达**：
   - 搜索框常驻顶栏，按 `/` 或 `Ctrl+K` 聚焦，输入即过滤。
   - 点卡片直接打开网址。
   - 左栏点一下就筛选。
   - 卡片 / 列表切换是顶栏的分段控件。
   - 「整理」是顶栏唯一的主按钮。
   - 应用后「撤销」就在结果条上。
6. **毛玻璃只用在顶栏、左栏和整理页的底部工具条**（还有对话框背后的遮罩），内容区不用。
7. **同一时刻最多一个主按钮给当前这一步**：顶栏「整理」之外，整理页没有方案时主按钮是「生成方案」，有方案后让给底部的「应用」；整理页第 ① 步的「抓取网页信息」是灰按钮；待处理的内容区没有主按钮（删除不用蓝色主按钮，批量删除是主色链接）；确认框里的确认按钮是主按钮。
8. **行内操作平时隐藏**：方案预览里的改名、合并、移除、换目录，卡片和列表行上的移动、删除、编辑，悬停或键盘聚焦这一行时淡入（只改透明度），平时只显示名称和数量。例外：方案预览里「待整理」「待清理」两组的「放到」一直显示，待处理里每一行的「放到」「删除」一直显示（那里本来就是要你处理的）。
9. **每个数字点进去都有办法处理**：顶栏、弹窗上出现的数（待处理 M、放好 N 条）点了直接到能处理它的地方；每个列表的每一条都有出口（放到某个文件夹或删除），处理完从列表里消失，结果条能撤销。工具栏角标只数还没放好的新收藏，点一次「放好」就清零，设置里能关。

## 颜色

浅色 / 深色跟随系统，设置里可以固定。数值取 iOS / macOS 的系统语义色。

| token | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--accent` | `#007AFF` | `#0A84FF` | 主色 |
| `--accent-fill` | `rgba(0,122,255,0.12)` | `rgba(10,132,255,0.22)` | 左栏选中行底色 |
| `--bg` | `#F5F5F7` | `#000000` | 页面底 |
| `--surface` | `#FFFFFF` | `#1C1C1E` | 卡片、对话框、列表 |
| `--glass` | `rgba(246,246,248,0.78)` | `rgba(28,28,30,0.78)` | 顶栏、左栏（配合模糊） |
| `--label` | `rgba(0,0,0,0.85)` | `rgba(255,255,255,0.85)` | 正文 |
| `--secondary` | `rgba(60,60,67,0.6)` | `rgba(235,235,245,0.6)` | 次要文字、图标 |
| `--tertiary` | `rgba(60,60,67,0.3)` | `rgba(235,235,245,0.3)` | 占位符、禁用 |
| `--separator` | `rgba(60,60,67,0.12)` | `rgba(235,235,245,0.12)` | 分隔线、边框 |

| `--focus` | `rgba(0,122,255,0.5)` | `rgba(10,132,255,0.5)` | 焦点环：`outline: 3px solid`，贴着控件（offset 0），只在键盘操作时出现 |

毛玻璃：`background: var(--glass); backdrop-filter: saturate(180%) blur(20px)`。

## 动效

- 过渡 150ms，`cubic-bezier(0.25, 0.1, 0.25, 1)`，只改颜色、背景、透明度；不做位移、缩放、弹跳。
- 对话框和遮罩淡入 200ms。
- `prefers-reduced-motion: reduce` 时关掉全部过渡。

## 组件

- **顶栏**（玻璃，吸顶）：
  - 左：应用名「书签整理」，15px / 600。
  - 中：搜索框，占位符只写「搜索」。
  - 右：分段控件「卡片 | 列表」、灰按钮「待处理」（有要你拿主意的时后面带条数，同色、透明度 0.6）、主按钮「整理」（蓝底白字），然后设置按钮（只放图标，用 `aria-label`）。
  - 「待处理」「整理」在当前视图时显示选中样式（`--accent-fill` 底、`--accent` 字），再点一下回到浏览。待处理、整理视图里左栏不显示选中行。
- **左栏**（玻璃，固定）：
  - 分组「书签栏」「其他书签」。
  - 每行：文件夹图标（灰色线条）+ 名称 + 数量（右对齐，`--secondary`）。
  - 选中行：`--accent-fill` 底，文字和图标用 `--accent`。
  - 锁定的文件夹在数量前加一个灰色小锁。
- **浏览**：
  - 标题行：标题 + 数量（13px `--secondary`）；右侧是筛选和排序。筛选用灰色胶囊开关，选中时 `--accent` 文字、`--accent-fill` 底；排序用原生 `select`。
  - 卡片：`--surface` 底，没有边框也没有投影。从上到下：图标 + 标题（一行省略），说明（两行省略），底栏「域名 · 年月」+ 徽标（`--fill` 底、`--secondary` 字）。底栏高 20px（和徽标一样），贴卡片底边，同一行卡片的底栏对齐。悬停时底色叠一层 `--fill-hover`。
  - 没有网站图标时用首字母块：取标题里第一个字母、数字或汉字（跳过 emoji、括号、标点）。
  - 列表：`--surface` 容器，圆角 12px，行高 44px，行间用分隔线。
- **卡片上的操作**：悬停或聚焦时右上角出现移动、删除、编辑三个图标按钮（28px），底色和悬停时的卡片一样、圆角 8px，盖住标题的尾巴。移动打开「移动到」对话框（「放到」下拉 + 「新建文件夹…」：名称、放在哪），删除直接删、结果条能撤销。
- **待处理**：每一类是一块 `--surface` 底、圆角 12px 的分区：标题（15px / 600）+ 条数（`--secondary`），右边是批量操作（主色链接），下面一行 12px `--secondary` 的说明，再下面是行（最小高 48px，行间分隔线）。行：图标、标题、第二行（说明或原因 · 域名）、「放到」原生下拉（宽 200px，AI 猜的预选并写「（AI 猜的）」，旁边灰色小按钮「放进去」）、「删除」（`--secondary` 文字按钮）。空文件夹的清单收在 `details` 里，默认收起、默认全选。三类都空时是空状态「都处理完了」。底部 `details`「全部检查项」收着体检。
- **体检**（在「全部检查项」里）：数字网格，卡片里是大数字加一个短标签。书签、文件夹、书签栏顶层三张常驻，问题数为 0 的卡片不显示。点一张卡片，在下面列出对应条目。
- **整理**：
  - 设置用原生控件排成一行；「锁定」后面直接写锁定的文件夹名，点开在下一行勾选。
  - 下面四步，每步一行：20px 灰色圆形序号、步骤名（600）、一行 12px 说明。① 抓取网页信息（灰按钮，开抓前的清单、进度在这一步下面展开）② 生成方案（主按钮，先给没有说明的写说明）③ 检查方案 ④ 应用（按钮在底部工具条）。
  - 预览是两栏树（「现在」「整理后」，顶边对齐，数量都在行的最右边）加一个分组清单（`details` 分组，「待整理」「待清理」排在最前、默认展开）。锁定的文件夹在两栏里都列出、数量前加灰色小锁；「整理后」里排在方案目录后面（应用后它就在那个位置）。
  - 「应用」放在底部工具条上：贴内容区底边、占满内容区宽度、高 52px、玻璃底、上边一条分隔线；左边是方案数字（为 0 的不写），右边是主按钮。
- **结果条**：内容区顶部一条 `--surface` 横条，左边是结果数字，右边是「撤销」（链接样式，主色）。应用前底部条上的「移动 N」和应用后结果条上的「移动 N」是同一个数（已经在目标文件夹里的不算）。撤销后只写「已撤销」，有重建或保留的再写个数，名字放在「详情」里。待处理和卡片上的操作写「已放到「目录」」「已删除 N 条」「已删除 N 个空文件夹」，有跳过的加「· 跳过 N」。
- **弹窗**：搜索框；有还没放好的新收藏时一行「N 条新收藏还没放好」+ 占满宽度的主按钮「放好 N 条」，没有时一行灰字「✓ 新收藏都放好了」（不留点不了的按钮）；一键整理的结果一行（会换行）加「去处理」「撤销这次」链接；「待处理 M ›」整行能点；最近收藏；底部只有「管理页」。内部计数不显示。
- **确认框**：默认按钮是确认（主按钮，回车即确认），Esc 取消。
- **对话框**：原生 `dialog`，`--surface` 底，圆角 14px，阴影 `0 10px 40px rgba(0,0,0,0.18)`（只有对话框有阴影）。遮罩 `rgba(0,0,0,0.2)` + 模糊 8px。
- **设置**：字段竖排，标签 12px `--secondary` 在上，所有输入框右边对齐（显示 key 的眼睛按钮放在框里）。底部左边灰按钮「从备份恢复」，右边主按钮「完成」。初始焦点：没填 key 时在 key 输入框，否则在「完成」。
- **空状态**：居中，32px 灰色线条图标 + 13px `--secondary` 一个短词。
